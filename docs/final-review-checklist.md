# Final Review Checklist

Use this checklist before treating the repository as the final public portfolio submission.

## Repository narrative

- [x] The README explains the cross-functional business problem.
- [x] The README defines the shared KPI framework.
- [x] The functional views are described in business language.
- [x] The strongest DAX patterns are documented.
- [x] The performance workflow separates evidence from claims.
- [x] The semantic model is explained at a logical level.
- [x] The model inventory labels unverified metadata clearly.

## Technical validation

- [ ] Validate all 29 table names against a direct model export.
- [ ] Validate the 127-column count and field list.
- [ ] Validate all 65 measure names and DAX expressions.
- [ ] Validate all 28 relationships and their properties.
- [ ] Confirm the fact-table grains.
- [ ] Confirm the date and fiscal-year configuration.
- [ ] Replace the pending benchmark table with controlled before-and-after measurements if performance improvement is claimed.

## Attribution and publication

- [ ] Confirm the original source of the Business Insights 360 / AtliQ case study.
- [ ] State clearly which work was guided and which modeling, DAX, reporting, and performance-analysis work was completed independently.
- [ ] Confirm that the dataset and screenshots may be shared publicly.
- [ ] Decide whether the `.pbix` file can be published; keep it excluded until approved.
- [ ] Decide whether a license can be added; do not add one until ownership and redistribution rights are clear.

## GitHub presentation

- [ ] Review the repository description and topics.
- [ ] Check every README and documentation link.
- [ ] Confirm the default branch after the review PR is merged.
- [ ] Review the repository on desktop and mobile widths.
- [ ] Pin the repository on the GitHub profile after final approval.

## Final submission rule

The repository can be treated as final when the evidence, metadata, attribution, and public-sharing checks above are complete. Until then, the documentation is a review candidate rather than a finished evidence package.
