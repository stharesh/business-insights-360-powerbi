## Evidence standards

- Capture the real report or diagnostic tool; do not use recreated mockups as implementation evidence.
- Use PNG unless another format materially improves legibility.
- Crop irrelevant desktop chrome while retaining enough context to identify the view or tool.
- Keep KPI labels, chart titles, and important values readable at GitHub preview size.
- Use consistent report state and theme across dashboard captures.
- Remove credentials, connection strings, local file paths, and restricted data.
- Do not alter displayed values after capture.
- Record the report/model version used for the screenshots in the pull request or commit message.

See the [final review checklist](../docs/final-review-checklist.md) before publication.
