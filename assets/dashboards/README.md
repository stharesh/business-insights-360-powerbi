## Capture checklist

- Use the same report theme and comparable filter state.
- Ensure the page title and principal KPIs are visible.
- Prefer a full-page capture when labels remain readable.
- If a detail crop is necessary, retain the full-page image and add the crop as a separate clearly named file.
- Do not publish screenshots until the displayed data is approved for public sharing.

When these files are added, place the Executive view near the top of the main README and the functional views beside their relevant explanations.
